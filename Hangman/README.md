# Number Guessing Game

A Python-based interactive number guessing game featuring multiple
difficulty levels, score calculation, input validation, attempt tracking,
and automated testing.

## Features

- Easy, Medium, and Hard difficulty levels
- Random number generation
- Attempt tracking
- Score calculation
- Input validation
- Error handling
- Replay functionality
- Automated unit tests

## Technologies

- Python
- Object-Oriented Programming
- Random module
- Data Structures
- Exception Handling
- Pytest
- Git
- GitHub
