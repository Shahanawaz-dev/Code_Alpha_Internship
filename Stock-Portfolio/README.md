# Stock Portfolio Manager

A Python-based command-line application for managing stock holdings,
tracking investments, and calculating portfolio value.

## Features

- Add stocks to a portfolio
- Remove stocks from a portfolio
- Track share quantities
- Calculate average purchase price
- Calculate total investment
- View portfolio summary
- Input validation
- Error handling
- Automated unit tests

## Technologies

- Python
- Object-Oriented Programming
- Dictionaries
- Lists
- Functions
- Exception Handling
- Pytest
- Git
- GitHub
